Caimento do eixo para os dois bordos: cota do bordo = greide do eixo − inclinação × distância. Use 0 para pista plana.

#EstacaCota LEEixoCota LD

Toque no nº para selecionar a linha. Estaca em cinza = automática; digite nela para fixar (ex.: 12+10,00). Apague para voltar ao automático.

Formatos aceitos: Estaca;LE;Eixo;LD (ou Estaca;LE;LD), separador ; , ou tab — ou PNEZD com a descrição D = E12_LE, E12_LD, E12_EX.

EstacaTerr. LETerr. EixoTerr. LDGreide eixoProj. LEProj. LDLE C/AEixo C/ALD C/A

A = aterrar (projeto acima do terreno) · C = cortar (projeto abaixo do terreno). Linha rosa = greide do eixo; tracejada rosa = bordos de projeto. Toque numa linha da tabela para ver a seção.

Arraste para o lado no desenho para trocar de estaca. Azul = aterro, vermelho = corte.
